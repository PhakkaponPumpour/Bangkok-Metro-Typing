# METRO TH — MVP เกมพิมพ์ชื่อสถานีบนแผนที่

โปรเจกต์เรียนรู้ mechanics ของเกม "พิมพ์ชื่อสถานีแล้วรถไฟวิ่งไปตามเส้นทาง"
สร้างใหม่ทั้งหมดด้วยโค้ดของตัวเอง (ไม่ใช้โค้ดหรือ asset จากแอปอื่น)

## รัน

```bash
cd metro-th
npm install
npm run dev
```

เปิด http://localhost:5173

## โครงสร้าง

```
src/
  data/lines.ts        ข้อมูลสาย/สถานี (ตัวอย่าง)
  game/engine.ts       ตรรกะเกมล้วน ๆ (pure functions)
  game/geom.ts         interpolate พิกัดตามระยะทาง
  game/replay.ts       ghost / สถิติที่ดีที่สุด
  components/MapView.tsx
  components/HUD.tsx
  App.tsx
```

## โหมดภาษา

- สลับ **ไทย / EN** ที่มุมบนซ้ายของ HUD (ล็อกระหว่างเล่น)
- EN เปลี่ยนทั้ง UI และชื่อสถานีเป็นภาษาอังกฤษ (พิมพ์ ASCII เช่น `Phrom Phong`)
- แชร์ลิงก์ภาษาได้: `http://localhost:5173/?lang=en`
- ภาษาที่เลือกถูกจำไว้ใน `localStorage`

## Mechanics ที่ implement

- พิมพ์ชื่อสถานีถัดไปทีละตัวอักษร → ขบวนรถเลื่อนตามระยะจริงของเส้น
- ตัวอักษรถูก = +10 คะแนน, ครบสถานี = +100 และโบนัสคอมโบ
- ผิด 1 ครั้ง = คอมโบรีเซ็ต, นับเข้า accuracy
- 2 โหมด: ธรรมดา (จับเวลา), ไทม์ 90 วินาที
- Ghost: บันทึกสถิติที่ดีที่สุดต่อสาย+โหมด แล้วเล่นซ้ำเป็นคู่แข่ง
- ขบวนรถเลื่อนนุ่มนวล (interpolate ทุกเฟรม), หมุนตามทิศทางเส้นทาง และมี pulse ตอนเคลื่อนที่

## หมายเหตุสำคัญ

- **ข้อมูลสถานีใน `data/lines.ts` เป็นค่าประมาณ** สำหรับการเรียนรู้เท่านั้น
  ก่อนเผยแพร่จริงควรดึงจาก OpenStreetMap ผ่าน Overpass API
  และให้เครดิตตามสัญญาอนุญาต ODbL
- แผนที่ฐาน: Carto Dark Matter (ฟรี, มี attribution ในแผนที่แล้ว)
  เปลี่ยนได้ที่ `STYLE_URL` ใน `components/MapView.tsx`
- โลโก้/ฟอนต์/ข้อมูลของแอปต้นแบบไม่ถูกนำมาใช้
